# Ea’s Wedding

PWA (app instalable) para la wedding planner Ea’s Wedding: inicio con agenda, bodas, contratos en PDF (con o sin firma) y plantillas.

- Sin compilar: abrir `index.html` desde un hosting estático (GitHub Pages).
- Sincronización entre dispositivos: rellenar `firebase-config.js` y publicar `firestore.rules` en Firebase.
- Los datos viven en el dispositivo y, si se configura Firebase, en Firestore.
